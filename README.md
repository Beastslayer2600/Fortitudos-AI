# Fortitudo

One local workspace. One launcher.

**`Start Fortitudo Desk.bat`** starts the desk UI, the FA backend, and Ollama.

- Desk: http://localhost:8080
- Backend: http://127.0.0.1:8000
- Ollama: local models only

Use the desk for everything: Ask, Chat, Library, Clients, Drop zone, Learn & ingest, Social, Adjudication, Craft.

You remain responsible under FAIS. This is an evidence and drafting tool, not an FSP.

See `ONE_APP.md`.

## First run

1. Node.js, Python 3, Ollama (`ollama pull llama3.2:3b` and `ollama pull bge-m3`)
2. Clone this repo
3. `npm install` and `pip install -r backend/requirements.txt`
4. Double-click `Start Fortitudo Desk.bat`
5. In the desk open **Learn & ingest** and drop product PDFs. File client docs on the client, then re-index.
