# Craft design doctrine

Applies to: craft

A Fortitudo Craft page exists so a stranger in that suburb can call in one tap.

## Order of thinking
1. Intent — emergency (call now) or appointment (hours + place).
2. Audience — one person, one suburb, one job.
3. First screen — suburb, job, Call.
4. Headline — job + suburb. Never a slogan.
5. Proof — only what the brief contains.
6. Omit — hours, reviews, prices if not supplied.
7. Flyer line — same job, A6 length.

CTA: Call first, WhatsApp second.
Mood: industrial | warm | cool | lush. No hex. No HTML.
Never invent 24/7, awards, testimonials, or a second location.
